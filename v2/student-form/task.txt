Student Registration Form - Task Description

Task:
Create a Student Registration Form using HTML, Bootstrap, and json-to-tag.

Requirements:
1. Student Name input field
2. Mobile Number input field
3. Register button

Implementation:
- Created the form using a JSON specification.
- Used the json-to-tag CDN to generate HTML elements from the JSON specification.
- Used Bootstrap 5.3.3 for styling and responsive design.
- Added a centered registration form with a clean card layout.
- Added input fields for Student Name and Mobile Number.
- Added a Register button using Bootstrap classes.
- Added form submission handling using JavaScript.
- Used preventDefault() to prevent the page from refreshing when the form is submitted.
- Displayed the entered Student Name and Mobile Number in the browser console.

Purpose of json-to-tag:
json-to-tag is used to generate HTML elements from a JSON specification instead of writing the HTML elements directly.
