Student Registration Form - Task Description

Task:
Create a Student Registration Form using HTML, Bootstrap, and json-to-tag.

Requirements:
1. Student Name input field
2. Mobile Number input field
3. Register button

Implementation:
- Created the Student Registration Form using HTML.
- Used Bootstrap 5.3.2 through CDN for styling and responsive design.
- Used Bootstrap classes for the layout, form fields, card, and button.
- Used json-to-tag CDN to generate the HTML elements from a JSON schema.
- Created the form structure using a JSON schema.
- Added Student Name and Mobile Number input fields.
- Added a Register button.
- Used Bootstrap utility classes such as container, shadow, rounded, text-center, and w-100.

Purpose of json-to-tag:
json-to-tag is used to create HTML elements dynamically from a JSON schema instead of writing all HTML elements directly.

- index.html - Student Registration Form
